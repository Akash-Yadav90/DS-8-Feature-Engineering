# DS-8 Feature Engineering

## Project Overview

This project demonstrates feature engineering and machine learning
on online retail transaction data.

The objective is to create useful historical and temporal features,
train a regression model, and compare its performance with a baseline.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regression
- Git and GitHub
